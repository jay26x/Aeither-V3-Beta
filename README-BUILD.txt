Aether Client - Fabric source project
Minecraft target: 1.21.11
Java: 21

Build on a machine with internet access and Gradle installed:
  gradle build

The output should be in build/libs/Aether-Client-1.0.0.jar.

This source archive did not include a Gradle wrapper or wrapper JAR. Gradle must be installed locally, or generate a wrapper with `gradle wrapper` first. The first build downloads Minecraft, Fabric Loom, Loader, and Fabric API dependencies.

Build errors may still occur because the source code has not yet been compiled against these dependencies. If that happens, share the full Gradle error output so the project can be corrected.
