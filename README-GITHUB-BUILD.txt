Aether Client - Fabric 1.21.11 source

This archive includes the source code, Gradle build files, and .github/workflows/build.yml.
The default UI theme is set to Amethyst (black/purple with violet accents). Existing modules/settings are left in place.

Build on GitHub:
1. Extract this ZIP.
2. Put the CONTENTS of the extracted folder in the root of your GitHub repository (the .github folder must be visible at the repo root, not nested inside another folder).
3. Commit and push the files.
4. Open the repository's Actions tab and run/inspect "Build Aether Client".
5. Open the successful run, go to Artifacts, and download Aether-Client-JAR.
6. From the downloaded artifact, use Aether-Client-1.0.0.jar (not the -sources.jar) in your Minecraft 1.21.11 mods folder.

This is source code; the JAR is generated by GitHub Actions. A successful workflow is required before installing it.
